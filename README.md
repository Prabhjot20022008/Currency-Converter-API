  <h1>💱 Currency Converter</h1>
  <p>
    A responsive and beginner-friendly currency converter built with <strong>HTML</strong>, <strong>CSS</strong>, and <strong>JavaScript</strong>,
    using real-time exchange rates from the <a href="https://www.floatrates.com/" target="_blank">FloatRates API</a>.
    This project was created to practice API integration, DOM manipulation, and UI building.
  </p>

  <h2>🔧 How to Run Locally</h2>
  <div class="highlight">
    <ol>
      <li>Clone the repository:</li>
      <pre><code>git clone https://github.com/Prabhjot20022008/currency-converter.git
cd currency-converter</code></pre>
      <li>Open <code>index.html</code> in your browser.</li>
    </ol>
  </div>

  <h2>✨ Features</h2>
  <ul>
    <li>🔁 Convert between 150+ world currencies</li>
    <li>🌐 Live exchange rates using FloatRates API (no API key required)</li>
    <li>🇺🇸 Flag icons that update based on selected currency</li>
    <li>✅ Input validation and same-currency handling</li>
    <li>📱 Clean and responsive design</li>
  </ul>

  <h2>🛠 Technologies Used</h2>
  <ul>
    <li>HTML5, CSS3, JavaScript (ES6)</li>
    <li><a href="https://www.floatrates.com/" target="_blank">FloatRates API</a> – currency exchange data</li>
    <li><a href="https://flagsapi.com/" target="_blank">FlagsAPI</a> – flag icons</li>
  </ul>

  <h2>🧠 Learning Outcomes</h2>
  <ul>
    <li>Working with public APIs using <code>fetch()</code></li>
    <li>Parsing JSON responses</li>
    <li>Dynamic DOM updates and element creation</li>
    <li>Handling user input and edge cases</li>
  </ul>
